# Библиотека по биомеханике

Веб‑сервис для хранения и поиска материалов по биомеханике: **статьи** (с пометкой «научная статья») и **видеоролики**.  
Каждый материал относится к одному из трёх разделов (enum) и имеет **основного автора** и **соавторов**.


## Возможности

- CRUD для **статей** и **видеороликов** (разные сущности/таблицы).
- Пометка «**научная статья**» для статей (опционально — для видео, если нужны научные видеолекции).
- Связи авторства: **1 основной автор** + **0..N соавторов**.
- **Единая точка поиска** с комбинированием фильтров (фамилия автора, фамилия соавтора, название, раздел, тип, научность).
- Пагинация и сортировка (`page`, `size`, `sort`).
- Контроллеры возвращают **DTO**, маппинг из сущностей делается через **MapStruct** (или вручную).
- Поиск реализован через **JPA Specification** (для SQL) — предпочтительный вариант.

> Если *тип фильтра* (author/coauthor/title) не задан, поиск идёт по **всем трём** полям и по **всем разделам**; если указан `section` — область поиска **сужается** до этого раздела.

## Технологии

- Java 17+, Spring Boot 3.x
- Spring Web, Spring Data JPA (Hibernate)
- PostgreSQL 14+ (или другая SQL‑СУБД)
- MapStruct (маппинг Entity ↔ DTO)
- Lombok (по желанию)
- Testcontainers/JUnit 5 (тесты)
- Docker/Docker Compose (локальный запуск)
